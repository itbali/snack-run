# План 15. Рыбалка — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Два рыбака на краю причала ловят рыбу; пойманная «Золотая рыбка» (легендарная, только так) лежит в ведре позади рыбака — кот крадёт её, пока рыбак смотрит на воду; если кот у ведра, когда рыбак поворачивается, — рыбак шугает (удар, еда рассыпается). Ночью рыбаков нет.

**Architecture:** Узел `Fisher` (`scripts/hazards/fisher.gd`, сцена `scenes/hazards/fisher.tscn`): модель человека новой роли `fisher` (CC0 Quaternius Animated Human, жилет и панама), удочка, поплавок на воде, ведро позади. Цикл — статическая `Fisher.next_phase(phase, t, watch)` с юнит-тестом: `watch` (10–20 с) → `bite` (1 с, поплавок дёргается, всплеск) → `pull` (2 с, клип work) → `look` (3 с, повернулся к берегу; в начале — проверка «кот у ведра») → `watch`. В конце `pull` в ведре появляется `FoodPickup` с `golden_fish` (одна за раз). Расстановка — `data/layout_src/port.json`, торец причала.

**Tech Stack:** Godot 4.7.2 + GUT, Blender 5.2.2.

**Spec:** `docs/superpowers/specs/2026-10-09-snack-run-stage3-port-design.md`, раздел 4 (и 5 — золотая рыбка).

## Global Constraints

- 2 рыбака на торце причала (не на полосе погрузчика), удочка и ведро позади (к берегу).
- Цикл: смотрит на воду 10–20 с → клюёт (поплавок дёргается, всплеск) → 2 с вытягивает → рыба в ведро → 3 с смотрит в ведро → снова к воде.
- Кража: пока рыбак смотрит на воду, кот берёт рыбу из ведра (обычный подбор). Кот ближе 1 м к ведру в момент поворота — удар, еда рассыпается.
- Днём и вечером; ночью рыбаков нет (и рыбы в ведре нет).
- Золотая рыбка появляется только из ведра.

## Review Focus

1. В ведре не больше одной рыбки; украденная не возвращается до следующего улова.
2. Шугание только в момент поворота и только ближе 1 м; спрятанного/в безопасной зоне не шугает.
3. Ночью рыбак исчезает вместе с рыбкой; утром возвращается.
4. Рыбак, удочка и ведро не перекрывают полосу погрузчика и проходы.
5. Рыбку можно унести домой (обычная еда в зубах), альбом получает золотую рыбку.
