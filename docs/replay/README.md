# Snack Run: инструкция для воспроизведения с нуля

Эта папка — полная инструкция, по которой другой ИИ-агент (или человек) повторяет всё,
что было сделано в проекте, начиная с пустой папки с тремя концепт-артами и заканчивая
играбельным «фундаментом»: кот с анимациями бегает по двору, модели собираются из Blender
скриптами, тесты зелёные.

## Что должно быть установлено заранее (ставить не нужно, уже есть)

| Инструмент | Версия | Путь |
|---|---|---|
| Godot | 4.7.2 stable (обычная сборка, не .NET) | `/Applications/Godot.app/Contents/MacOS/Godot` |
| Blender | 5.2.2 LTS (Python 3.13, numpy внутри) | `/Applications/Blender.app/Contents/MacOS/Blender` |
| uv | любой свежий | `/opt/homebrew/bin/uv` (нужен только для UniMate) |
| OpenAI API | ключ в `OPENAI_API_KEY` | только для перегенерации картинок (`make images`); модель `gpt-image-2.5` |
| Homebrew, git, curl, python3 | системные | — |

Машина: Apple Silicon (M4 Pro), macOS. CUDA нет, UniMate работает на CPU.

## Исходные данные

Три PNG 1536×1024 в папке проекта (в этом репозитории они лежат в `reference/`):
- «Котёнок в погоне за пиццей» — ключевой кадр стиля;
- «Карта приключений кота Snack Run» — карта мира, районы, редкости, опасности;
- «Артборд ассетов для игры про котика» — кот, еда, враги, пропсы, палитра.

## Как пользоваться

Читать и выполнять по порядку:

1. `01-decisions.md` — вопросы, которые были заданы владельцу, и его ответы. Их **не нужно
   задавать заново**: это зафиксированные решения. Здесь же правила владельца.
2. `02-procedure.md` — пошаговая процедура: что создать, какие команды выполнить, что должно
   получиться на каждой контрольной точке, и какие грабли уже известны.
3. `03-files.md` — приложение с полным содержимым всех файлов проекта (генерируется командой
   `make replay`). Когда процедура говорит «создать файл X», содержимое берётся отсюда.

Два документа из `docs/superpowers/` входят в приложение целиком и обязательны к прочтению
перед началом: спек `2026-10-07-snack-run-design.md` (источник истины по дизайну) и дорожная
карта `2026-10-07-snack-run-roadmap.md`.

## Что считается успехом

- `make test` зелёный с чистого состояния (`rm -rf .godot && make test`): после плана 1 — 8 Blender-тестов и 29 GUT;
  после плана 4 — 20 Blender и 158 GUT; после плана 5 — 28 Blender и 180+ GUT; после этапа 2 (план 9) — 31 Blender и 240+ GUT (точные числа в разделах планов в `02-procedure.md`).
- `make assets` собирает все модели из `tools/blender/gen/*.py`; у `cat.glb` 6 клипов и четыре набора глаз, у `dog.glb` клипы idle/walk/sleep.
- `make shot` даёт кадр: гладкий рыжий кот с зелёными глазами, усами и ошейником на солнечном дворе с кустами, плющом, плакатами и декалями; белые плашки HUD (Nunito), виньетка по краям.
- `make images` при наличии `OPENAI_API_KEY` генерирует недостающие картинки по `tools/images/manifest.json` (иконки еды, фон заставки, облака, плакаты, декали); без ключа сгенерированные PNG уже лежат в репозитории.
- `make run`: WASD двигает кота относительно камеры, мышь/Q/R крутят камеру, Shift бег, Space прыжок, Ctrl прятаться, E есть/магазин, Tab альбом, Esc пауза.
- `make export` (после `make templates`) даёт `build/SnackRun.zip` с `SnackRun.app`.

## Принципы, которые нельзя нарушать при воспроизведении

- Ничего не покупать. Только бесплатные ассеты (CC0/CC-BY).
- Анимации не рисовать самому: готовые паки → UniMate → генерация скриптом только если ничего нет.
- Модели только скриптами Blender (`bpy`), никакой ручной работы в GUI.
- Сначала тест, потом код (TDD). Каждая задача заканчивается коммитом.
- Все тексты, комментарии, коммиты на русском; идентификаторы кода на английском.
- Коммиты заканчиваются строкой `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` (если воспроизводит другая модель — подставить своё имя).

## Поддержка инструкции

Каждая следующая сессия, которая меняет проект, обязана:
- дописать новые шаги в `02-procedure.md` (что сделала, какие команды, что проверила);
- выполнить `make replay`, чтобы приложение отражало текущие файлы;
- новые грабли добавить в раздел «Известные грабли» в `02-procedure.md`.
